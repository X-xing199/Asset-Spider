## ✨ 功能特点

### 🚀 统一聚合扫描（核心特色）

**一次输入目标，自动串联全部功能，输出一条完整汇总结果：**

| # | 扫描模块 | 输出内容 |
|---|---------|---------|
| 1 | 子域名扫描 | 存活子域名 + 状态码 + 标题 + IP |
| 2 | 中间件指纹 | 产品 + 版本 + 分类 + 置信度评分 |
| 3 | 目录发现 | 可访问路径 + 状态码 + 标题 |
| 4 | 端口扫描 | 开放端口 + 服务名 |
| 5 | 威胁匹配 | JS 中的敏感参数分类（密码/SSRF/命令注入等） |
| 6 | JS 路径勘探 | JS 中提取的路径/接口（含动态拼接） |
| 7 | JS 敏感信息 | API Key / Token / 私钥等泄露检测 |
| 8 | Favicon 指纹 | FOFA / Hunter / Quake 查询语法 |
| 9 | FUZZ 攻击存活 | 各攻击类型的存活请求 |
| 10 | Bing 搜索 | 敏感信息泄露页面搜索 |

统一模式下**自动使用默认参数、跳过交互询问**，一条流水线跑完所有模块，最后只展示有结果的类别，空类别一行汇总，输出干净聚焦。

### 🔍 六大扫描模块

| 模块 | 模式 | 功能描述 |
|------|------|---------|
| **子域名扫描** | ℹ️ 信息收集 | 子域名字典爆破 + DNS 解析 + 连通性测试，不含漏洞评估 |
| **中间件指纹** | ⚠️ 推测性评估 | 多维度指纹识别 + 主动探测 + CVE 匹配 + 推测性漏洞类型猜测 |
| **端口扫描** | ℹ️ 信息收集 | 高危/全端口扫描 + 200+ 端口服务映射，不含漏洞识别 |
| **FUZZ 攻击** | ⚠️ 推测性评估 | 路径爆破 + 13 种攻击类型 + AI 赋能爆破路径 |
| **JS 路径勘探** | ℹ️ 资产勘探 | JS 文件抓取 + 路径/接口提取 + 动态拼接路径 + 威胁匹配 + Favicon 指纹 |
| **Bing 联合搜索** | ℹ️ 信息收集 | 按自定义语法搜索目标域名的敏感信息泄露页面 |

### 🧠 AI 智能赋能（推测性分析，不含利用方法）

- **推测性漏洞类型分析**：遵循 CVE/CWE 标准分类，提供漏洞类别、影响范围、风险等级
- **JS 深度审计**：支持自定义审计提示词模板（`config/js_audit_prompt.json`），AI 拼接完整 URL+参数并给出威胁评价
- **JS 逻辑推测性分析**：分析前端认证机制、API 端点、数据流
- **AI 赋能爆破路径**：URL 无参数时 AI 推荐可能存在漏洞的路径并自动 FUZZ
- ⚠️ 所有 AI 分析结果均标注「推测性结果」，不包含具体利用方法或验证步骤

### 🎨 可视化输出

- **6 级漏洞颜色分级**：严重(红加粗)/高危(红)/中高危(黄)/中危(蓝)/中低危(青)/低危(紫)
- **推测性结果标注**：漏洞猜测统一标注「[推测性结果]」前缀
- **统一聚合输出**：所有功能结果汇总为一条完整结果

### ⚡ 性能优化

- **Session 连接池**：所有 HTTP 请求复用连接（keep-alive），减少 TCP 握手
- **字典缓存**：基于文件修改时间的字典缓存机制，避免重复读取大文件
- **多线程并发**：线程数可通过配置调整
- **Windows 编码修复**：自动处理 GBK/UTF-8 编码问题

## 🚀 快速开始

### 环境要求

- **操作系统**：Windows 10/11（推荐）、Linux、macOS
- **Python**：3.8 及以上（源码运行时需要）
- **依赖库**：`requests`、`openai`（源码运行时需要）

### 方式一：一键运行（推荐）

无需安装 Python 环境，直接运行 `AssetSpider.exe`：

```
AssetSpider v2.1/
├── AssetSpider.exe    # 主程序（onefile 打包）
└── config/            # 配置文件夹（可编辑）
    ├── ai_config.json      # AI 配置（可选）
    ├── settings.json       # 扫描行为主配置
    ├── headers.txt         # 自定义请求头
    ├── js_audit_prompt.json # JS 审计提示词模板
    ├── fingerprint.json    # 中间件指纹库
    ├── submin.txt          # 子域名字典
    ├── dir_dict.txt        # 目录字典
    └── ...
```

> 首次运行会在 exe 同级目录自动创建 `scan_logs/` 日志文件夹。

### 方式二：源码运行

```bash
git clone https://github.com/X-xing199/Asset-Spider.git
cd Asset-Spider

pip install requests openai

python AssetSpider.py
```

### AI 配置（可选）

AI 功能为可选，不配置也可正常使用所有扫描功能：

```json
// 编辑 config/ai_config.json
{
    "api_key": "你的API Key",
    "base_url": "https://api.deepseek.com",
    "model": "deepseek-v4-pro"
}
```

获取 API Key：[DeepSeek](https://platform.deepseek.com/api_keys)（推荐），或任意兼容 OpenAI 接口的服务。

## ⚙️ 配置管理

### 扫描行为主配置（`config/settings.json`）

无需改代码即可调整扫描引擎行为：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 线程数 | 全局默认线程数 | 15 |
| 禁止扫描 | 黑名单域名后缀（`|` 分隔） | `.gov\|.mil.cn` |
| 状态码过滤 | 丢弃区间内状态码 | `600\|700` |
| 长度过滤 | 丢弃区间内响应长度 | `0\|1` |
| 联合Bing搜索 | 是否启用 Bing 搜索 | OFF |
| Bing搜索语法 | 敏感信息搜索语法（`{url}` 替换为目标） | 身份证/学号/密码等关键词 |
| Bing搜索页数 | 每语法搜索页数 | 5 |
| 请求超时 | 全局请求超时(秒) | 8 |

### 自定义请求头（`config/headers.txt`）

按 `Header: Value` 格式配置，`random_headers()` 自动合并，支持覆盖默认头。

### JS 审计提示词模板（`config/js_audit_prompt.json`）

对应转子女神 AI.config 逻辑，让 AI 审计 JS 敏感信息、拼接完整 URL+参数并给出威胁评价。

## 🛡️ 合规性设计

AssetSpider 严格区分**信息收集**与**漏洞评估**：

| 模块 | 分类 | 输出内容 | 不包含 |
|------|------|---------|--------|
| 子域名扫描 | ℹ️ 信息收集 | 连通性 + DNS 解析记录 | ❌ 漏洞检测结果 |
| 端口扫描 | ℹ️ 信息收集 | 端口号 + 开放状态 + 服务名 | ❌ 漏洞识别 |
| 中间件指纹 | ⚠️ 推测性评估 | 指纹识别 + CVE 匹配 + 推测性漏洞类型 | ❌ 利用方法、验证步骤 |
| FUZZ 攻击 | ⚠️ 推测性评估 | 路径爆破 + FUZZ 测试 + 推测性漏洞类型 | ❌ 利用方法、验证步骤 |

所有 AI 分析 Prompt 均内置严格约束：仅提供漏洞类型分类（CVE/CWE 标准）、影响范围和风险等级，严禁输出利用方法、验证步骤、攻击链、WAF 绕过等操作指导。

## ❓ 常见问题解答

### Q: 统一聚合扫描和综合扫描有什么区别？
**A:** 统一聚合扫描一条流水线自动跑完所有功能（统一模式自动默认参数、跳过询问），最后输出**一条汇总结果**（10 类）；综合扫描是顺序执行各模块并分别展示结果。

### Q: AI 功能是否必须？
**A:** 不是。AI 为可选功能，不配置时所有扫描功能正常运行，仅缺少智能分析环节。

### Q: 支持哪些 AI 服务？
**A:** 任何兼容 OpenAI 接口的服务均可，默认 DeepSeek，修改 `config/ai_config.json` 的 `base_url` 即可切换。

### Q: 如何自定义扫描行为？
**A:** 编辑 `config/settings.json`（线程数/黑名单/过滤规则/Bing 语法），或编辑 `config/headers.txt`（请求头），无需改代码。主菜单 [5] 配置管理可查看/热重载。

### Q: 扫描速度慢怎么办？
**A:** 1. 调整 `settings.json` 线程数；2. 端口扫描选高危模式；3. 使用更小的字典文件。
